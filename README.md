# Re:hear - 발표 훈련 설정

## 사용자와 목표

- 사용자: 발표를 준비하는 사람
- 목표: 훈련 조건을 정하고, 설정한 내용을 확인한다.

## 사용자의 흐름

1. 녹음 활용에 동의하고 '훈련 설정 시작하기'를 누른다.
2. 발표 제목을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 발표 시간을 선택하고 필요하면 질의 응답을 포함한다.
4. 제목, 시간, 질의응답 설정을 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터랙션 시나리오

1. 시작과 녹음 활용 안내

- 행동, 이벤트: 기존 동의 체크박스를 선택하고 '훈련 설정 시작하기'를 클릭한다.
- 조건: 녹음 활동 동의가 선택되었는가?
- 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다.
  팝업에서 '돌아가기'를 누르거다 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
  '동의하고 설정 시작하기'를 누르면 제목 입력 화면을 연다.

2. 제목 입력

- 행동, 이벤트 : 제목을 적고 '훈련 조건 선택하기'를 클릭한다.
- 조건: 앞뒤 공백을 지운 제목이 비어 있는가?
- 반응, 다음상태 : 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
  값이 있으면 저장하고 조건 선택으로 이동한다.

3. 조건 선택

- 행동, 이벤트: 발표 시간을 바꾸나 질의응답을 선택하고 '내용 확인하기'를 클릭한다.
- 조건: 질응응답을 선택했는가?
- 반응, 다음 상태: 선택했을 때만 질문 수를 보여준다.

4. 내용 확인

- 행동, 이벤트: 제목, 시간, 질의응답 내용을 읽고 ' 수정하기' 또는 '설정 완료하기'를 클린다.
- 조건: 수정인가, 완료인가?
- 반응, 다음 상태: 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
  완료하면 완료 안내로 이동한다.

5. 완료와 다시 설정

- 행동, 이벤트: 완료 안내를 일고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음 상태: 새 설정의 제목, 시간, 질의응답, 진행 상태를 초기화하고 제목 입력부터 다시 시작한다.
  이미 확인한 녹음 활용 동의와 다른 기능을 유지한다.
