## 13주차 QA

1. 시작 조건: 제목 ' 프로젝트 발표 연습', 이름 '보라', 발표 시간 10분, 질의응답 선택
2. 행동: 최종 저장 전에 브라우저 새로고침
3. 기대 결과: 작성하던 제목, 이름, 선택 조건이 남아 있어서 이어서 작성이 가능
4. 실제 결과: 빈 양식으로 돌아와 같은 내용을 다시 입력해야함
5. 사용자 영향, 예상: 같은 내용을 다시 작성해야함.
6. 재확인 기준: 수정 뒤 같은 조건에서 값과 선택 상태가 돌아오는지 확인.
7. 수정: 입력, 선택값과 1-3단계 위치를 현재 탭에 임시 보관
8. QA 재확인: 2-3단계 새로고침 뒤 값,단계, 요약, 안내 확인
9. 다른 경로: 처음부터 입력하기, 저장 성공 후 임시값 삭제 확인
10. 사용자 테스트
