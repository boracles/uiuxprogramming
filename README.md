# Re:hear 발표 훈련 계획 프로토타입

> 교사용 8주차 중간고사 구현 예시입니다. 학생 제출물은 각자 기획한 서비스 주제를 사용해야 합니다.

## 서비스와 사용자

- **사용자:** 발표를 준비하며 연습할 내용을 미리 정하고 싶은 사람
- **목표:** 발표 제목과 연습 조건을 정한 뒤, 필요한 계획을 다시 찾아보기
- **주요 행동:** 발표 정보 입력 → 시간·질의응답 선택 → 내용 확인·수정 → 계획 저장 → 다시 열기 또는 취소

이 페이지는 브라우저에서 조작하는 중간 프로토타입입니다. 녹음, AI 청중, 피드백 생성 기능은 구현하지 않았습니다. 완성한 계획은 별도 서버 없이 현재 브라우저의 저장 공간에만 남습니다.

## 7주차 결과물에서 새로 추가한 것

기존의 발표 제목 입력, 훈련 조건 선택, 확인·수정 흐름에 **완성한 훈련 계획을 보관함에 저장하고 다시 열어보는 행동**을 연결했습니다. 저장한 계획을 취소하면 상태와 진행 중 개수가 바뀌며, 취소를 되돌릴 수도 있습니다.

기존 화면의 실제로 작동하지 않는 녹음 동의·구독 안내와 과도한 기능 소개를 정리했습니다.

## 새 기능의 행동과 분기

| 사용자 행동                   | 확인할 조건                  | 화면 반응                                                 | 다음 행동                              |
| ----------------------------- | ---------------------------- | --------------------------------------------------------- | -------------------------------------- |
| 제목을 비운 채 다음 단계 선택 | 공백을 제외한 제목이 있는가? | 입력창 아래에 고치는 방법을 표시하고 입력창으로 초점 이동 | 제목 입력 후 다시 진행                 |
| 조건 선택 후 내용 확인        | 시간과 질의응답 선택값       | 제목·이름·시간·질문 수를 요약에 반영                      | 해당 단계 수정 또는 저장               |
| 계획 저장                     | 유효한 제목이 있는가?        | 완료 안내와 내 계획 카드 생성, 진행 중 개수 증가          | 카드에서 내용 보기 또는 새 계획 만들기 |
| 카드의 내용 보기              | 선택한 계획이 목록에 있는가? | 저장한 값을 대화상자에 표시                               | 닫고 목록으로 돌아가기                 |
| 계획 취소                     | 현재 저장 상태인가?          | 카드를 ‘취소됨’으로 바꾸고 진행 중 개수 감소              | ‘취소 되돌리기’ 또는 새 계획 만들기    |
| 취소 되돌리기                 | 현재 취소 상태인가?          | 카드를 ‘저장됨’으로 되돌리고 개수 증가                    | 다시 열어 확인하기                     |
| 새 계획 만들기                | 완료 화면인가?               | 입력·선택·진행 단계만 초기화; 보관함의 이전 계획 유지     | 다른 계획 입력                         |

보관함이 비어 있으면 빈 상태와 ‘계획 만들러 가기’ 링크가 나타납니다. 브라우저 저장 공간을 사용할 수 없으면 현재 화면에서는 동작하지만 새로고침 뒤 사라질 수 있다는 안내를 표시합니다.

## 직접 시험한 기록

2026-09-25, 로컬 미리보기(`http://127.0.0.1:8765/`)에서 확인했습니다.

1. **오류 경로:** 제목 없이 ‘훈련 조건 선택하기’를 누르자 오류 안내가 표시되고 제목 입력창으로 초점이 이동했습니다.
2. **정상 경로:** 제목과 이름을 입력하고 10분·질문 3개를 선택하자 확인 화면에 모든 선택값이 반영됐습니다.
3. **수정 경로:** 확인 화면에서 정보 수정으로 돌아가 제목을 바꿨습니다. 이름과 훈련 조건은 유지됐고 새 제목이 다시 확인 화면에 표시됐습니다.
4. **저장·다시 열기:** 저장 후 보관함에 카드와 진행 중 개수 1이 나타났고, ‘내용 보기’에서 저장값을 다시 확인했습니다. 새로고침 뒤에도 계획이 남았습니다.
5. **취소·되돌리기:** 취소 후 카드가 ‘취소됨’으로 바뀌고 개수가 0이 됐습니다. ‘취소 되돌리기’로 다시 1이 됐습니다.
6. **화면 너비:** 데스크톱과 390px 모바일 화면에서 정보 입력, 시간 선택, 질의응답, 버튼 및 보관함 카드를 확인했습니다. 모바일에서 입력창이나 버튼의 겹침·가로 밀림은 보이지 않았습니다.
7. **로고:** Figma 원본 이미지가 헤더와 푸터에 표시되는지 확인했고, 밝은 화면과 다크 모드에서 읽을 수 있었습니다.
